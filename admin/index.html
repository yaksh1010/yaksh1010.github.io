First-time setup (2 minutes):
  1. Sign up free at goatcounter.com/signup and pick a code, e.g. yaksh1010.
  2. Paste that code in the field above.
  3. In GoatCounter → Settings → Site settings, tick “Allow adding visitor counts to your website”. That's what lets this page read your numbers.
  4. Hit Export data.js in the Publish tab and commit. Tracking starts on the next visit.

Publish

Your edits live in this browser until you export. Exporting writes a new data.js — replace the old one and commit.

Every time you change something

  1. Click Export data.js below — it downloads.
  2. Move it into your repo folder, replacing the existing data.js.
  3. If you added screenshots, save the image files into images/ using the exact filenames the panel showed you.
  4. git add . && git commit -m "update projects" && git push
  5. GitHub Pages rebuilds in ~30 seconds. The site never goes offline — the old version serves until the new one is ready.

Danger zone

Your working copy is kept in this browser's storage, so a refresh won't lose it.
